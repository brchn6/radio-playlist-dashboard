## What Was Built

### Core Analysis Engine (`scripts/radio_utils.py` - 143 lines)
Shared module with: `load_tracks`, `filter_by_slot`, `group_by_song`, `build_pair_counts`, `build_neighbor_graph`, `pagerank`, `STATIONS`, `PROJECT`, `stderr`.

### 1. Frequency + PageRank Selector (`scripts/playlist_selector.py` - 269 lines)
- Filters tracks by station + time slot (local Israel time, UTC+3)
- Computes frequency score (days played / max days)
- Builds undirected co-occurrence graph (tracks played 3-15 min apart)
- Runs PageRank from scratch (no numpy/networkx)
- Combined score: `alpha * freq + (1-alpha) * pagerank`
- Outputs ranked JSON + human-readable summary

### 2. Co-occurrence Graph Export (`scripts/export_graph.py` - 207 lines)
- Exports vis.js graph data for the simpler co-occurrence visualization

### 3. Markov Chain + Community Analysis (`scripts/markov_analysis.py` - 550 lines)
- Directed transition counts (A->B, not just A-B)
- Transition matrix (normalized to probabilities)
- Stationary distribution (power iteration, equivalent to PageRank)
- Random walk scoring (1000 walks x 30 steps)
- Node entropy (deterministic vs unpredictable transitions)
- Label propagation community detection (with resolution parameter)
- Knee plot data (modularity vs community count across resolutions)
- Vis.js export with communities color-coded

### 4. Streamlit Dashboard (`scripts/app.py` - 189 lines)
- Station selector, time range, alpha slider, min-days filter
- Editable table with checkboxes, score progress bars
- Export selected tracks as `selected_tracks.txt`
- Runs `playlist_selector.py` via subprocess, caches results

### 5. Interactive Visualizations
- `docs/cooccurrence-graph.html` - vis.js, station selector, search, click for details
- `docs/markov-graph.html` - vis.js, community panel (click to focus), directional edges
- `docs/playlist-explorer.html` - static dashboard (legacy, earlier iteration)

### 6. Research Baseline (`docs/RESEARCH-PLAYLIST-SELECTION.md`)
- 10 analytical approaches documented (3 done, 7 TODO)
- See `.context/playlist-selection-research.md`

4. **HTTP server for visualizations** - `python3 -m http.server 8502 --directory docs` must be running on head1 for the vis.js pages to load JSON data. Currently running from this session (may have died).
